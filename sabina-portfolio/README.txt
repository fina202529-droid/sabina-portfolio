SABINA NEUPANE — PERSONAL WEBSITE

Files:
- index.html
- style.css
- script.js
- assets/sabina-profile.jpeg
- assets/speech-contest.jpeg

How to run:
1. Extract this folder.
2. Open the folder in VS Code.
3. Open index.html in a browser, or use the Live Server extension.

Before publishing:
- Replace the GitHub link in index.html with your actual profile URL.
- Review the personal information and photos you want to make public.
- Add a professional email/contact link only if you want it public.

The site uses Google Fonts, so an internet connection is needed for those fonts.
